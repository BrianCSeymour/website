Embedding the interactive waveform explorer

This page is an example of a third-party site embedding the explorer built by Brian Seymour and hosted at briancseymour.com. Everything below the presets is a plain <iframe>.

Optional preset links. Changing the hash of the frame re-drives the explorer without a reload:

  • Equal mass, no spin
  • q = 3, aligned spin
  • Strongly precessing, inclined

Minimal version

If you do not want presets or auto-sizing, this is all that is needed:

<iframe
  src="https://www.briancseymour.com/assets/interactive/waveform-explorer.html#q=3&ce=0.5&cp=0&rq=1&rce=0&rcp=0&view=mode&inc=0&win=late"
  title="Interactive SEOBNRv5 waveform explorer"
  style="width:100%;height:1100px;border:0"
  loading="lazy"></iframe>
